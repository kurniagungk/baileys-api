## Critical

### 1. `restartRequired` path doesn't strip `res` from options

- **File:** `src/whatsapp/service.ts:126-128`
- **Source:** [review] — flagged by 7 of 9 agents
- **Issue:** The `restartRequired` early-return passes the full `options` object (including the stale `res` HTTP Response) to `createSession`. The two Bad MAC recovery paths correctly strip `res` with `const { res: _res, ...recoveryOptions } = options`, but this path was missed.
- **Impact:** Writing to a closed HTTP response can throw `ERR_HTTP_HEADERS_SENT` or silently fail. Same class of bug the Bad MAC handlers were specifically patched to fix.
- **Suggested fix:**
```typescript
if (restartRequired) {
    WhatsappService.retries.delete(sessionId);
    const { res: _res, ...recoveryOptions } = options;
    setTimeout(() => WhatsappService.createSession(recoveryOptions), 0);
    return;
}
```

### 2. Session `write` silently swallows all errors — no retry, no propagation

- **File:** `src/whatsapp/store/session.ts:18-30`
- **Source:** [review] — flagged by 6 of 9 agents
- **Issue:** Changed from Prisma `upsert` with 3-retry conflict handling to raw SQL `INSERT ON DUPLICATE KEY UPDATE`. The `catch` block only logs and returns void — no retry for transient errors, no `throw` to propagate failure.
- **Impact:** Transient DB errors cause permanent loss of auth state. On next restart, stale DB data triggers Bad MAC → session wipe → data loss cascade.
- **Suggested fix:** Re-add retry for transient errors and throw on final failure:
```typescript
const write = async (data: any, id: string): Promise<void> => {
    const fixedId = fixId(id);
    const stringified = JSON.stringify(data, BufferJSON.replacer);
    const MAX_RETRIES = 3;
    for (let attempt = 0; attempt <= MAX_RETRIES; attempt++) {
        try {
            await prisma.$executeRaw`
                INSERT INTO \`Session\` (\`sessionId\`, \`id\`, \`data\`)
                VALUES (${sessionId}, ${fixedId}, ${stringified})
                ON DUPLICATE KEY UPDATE \`data\` = VALUES(\`data\`)
            `;
            return;
        } catch (e: any) {
            if (attempt < MAX_RETRIES) {
                logger.warn({ sessionId, id: fixedId, attempt }, "Retry session write");
                await new Promise(r => setTimeout(r, 100 * (attempt + 1)));
            } else {
                logger.error({ sessionId, id: fixedId, err: e }, "Session upsert failed after retries");
                throw e;
            }
        }
    }
};
```
